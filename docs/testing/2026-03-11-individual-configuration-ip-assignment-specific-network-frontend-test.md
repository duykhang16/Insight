# Test Note: Individual Configuration IP Assignment Specific Network Frontend

## Expected Behavior

- `IP Assignment` shows two active radio choices
- selecting `Same as a Local Network` shows the wired-network dropdown
- selecting `Specific to This Network` shows:
  - Network Address
  - Subnet Mask
  - DNS Resolution
  - Primary/Secondary DNS fields
- selecting DNS `Automatic` disables the DNS input fields
- selecting DNS `Static` enables the DNS input fields
