# Test Note: Individual Configuration Radio Options 2.4 GHz Dependency

## Expected Behavior

- unchecking `2.4 GHz`:
  - hides `Radio Options`
  - clears `Extended 2.4 GHz range`
- re-enabling `2.4 GHz`:
  - shows `Radio Options` again
  - leaves `Extended 2.4 GHz range` off until the user re-enables it
