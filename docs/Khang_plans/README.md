# Khang Plans Convention

This folder is the canonical location for ongoing work records from now on.

## Purpose

Each markdown here should record:

- the user request
- the working plan
- the key exchange or decisions
- the proposed code changes
- the implemented code changes
- verification or testing notes

## File Naming

Every record file name must include:

1. the date
2. the main topic or change

Recommended format:

`YYYY-MM-DD-main-topic.md`

Examples:

- `2026-03-11-auth-refresh-fix.md`
- `2026-03-11-zone-access-review.md`
- `2026-03-11-dashboard-api-mapping-update.md`

## Recording Rule

When a code modification is made:

1. record the modification details in the current markdown file for that task
2. when the work moves into a new task or topic, create a new markdown file in this folder to continue the record

## Template Sections

Use this section order unless the task needs a small adjustment:

- Metadata
- User Request
- Context Gathered
- Plan
- Exchange Log
- Proposed Changes
- Implemented Changes
- Verification
- Follow-up
